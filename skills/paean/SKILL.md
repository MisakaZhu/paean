# Paean · 口播视频配乐

以清楚的人声为主，音乐在底下托住内容。此公开版保留原混音配方；目录、曲库和导入目标由实际使用者提供，不继承作者的文件、软件状态或授权。

## 开始

1. 使用者提供成片文件夹或 Markdown 清单，并指定要处理的条目；未指定范围时先列清单，结合实际任务确认范围，不默认为所有本机视频。
2. 读 [configuration.md](references/configuration.md)。配置放在使用者工作目录 `.paean-config.json`，由 [config.example.json](config.example.json) 复制。没有配置时可用完整来源路径及 CLI 参数，默认只输出 `./paean-work`。
3. 使用已安装且含 NumPy 的 Python 运行本 skill 的脚本；媒体工具按当前环境解析为绝对路径。缺少依赖就说明实际缺项，不使用作者机器的绝对路径，不自动改动系统环境。
4. 曲库由使用者自行提供且须有权使用。包内没有商业音乐、剪映缓存、真实视频或历史配乐记录；不要为补齐曲目自行从网上下载音乐。

## 标准流程

命令中的 `SCRIPT_DIR` 换成已安装 skill 的 `scripts` 绝对路径，`SOURCE` 为使用者来源。PowerShell 调用带引号的 Python 路径时在前面加 `&`。

1. **先列清单**：`python SCRIPT_DIR/render.py SOURCE --list`。文件夹识别 `序号-标题（无音乐）.mp4`；Markdown 支持序号、标题、话题和本机成片链接，实际文件名不必等于标题。核对缺失文件、时长、话题与已有同名目标。
2. **定曲目**：按标题和话题检查建议曲目。关键词只作粗筛，例如“别长期照方喝”的“长期”不代表坚持主题。使用者允许自行选曲时自主选择其曲库里合适的项；不可用的别名通过配置映射或明确 `序号=曲目` 处理。
3. **渲染与验证**：`python SCRIPT_DIR/render.py SOURCE 1-`。可用 `16-`、`16-20`、`17`、`17=舒缓` 或 `16-20=传说`。每次生成独立运行目录，各条输出隔离；原视频保持原样。
4. **本机输出或导入**：没有 `destination_dir`/`--dst` 时只保存在工作区；配置了本机导入目标且任务要求导入时，将验证通过的文件保存到该目录。这里的“导入”是本机文件保存，不是调用像素蛋糕 API，也不代表抖音/视频号发布。
5. **汇报**：逐条给出序号、标题、曲目、响度、真峰值、验证结果与真实文件路径。缺失文件、同名未覆盖、失败与估计不确定性单独说明，不把失败项写成已完成。

脚本向本机 `配乐清单.md` 和 `render_log.jsonl` 追加实际记录，不上传日志。运行记录在 `WORK_DIR`，不写入已安装 skill 或公开仓库。

## 混音与选曲

完整配方和选曲规则见 [mixing.md](references/mixing.md)。默认人声比 BGM 高 `9 LU`，整体 `-16 LUFS`，真峰值 `≤ -1 dBTP`；视频流复制，不重新编码，输出音频为 AAC 192k、48 kHz 立体声。

常见调整：

| 要求 | CLI 参数 |
| --- | --- |
| BGM 大一点 | `--smr 7` |
| BGM 小一点、人声更突出 | `--smr 11` |
| 整体更响或更轻 | `--target -14` 或 `--target -18` |
| 只听预览，不导入 | `--no-publish` |
| 明确重做并替换目标 | `--replace`，同时指定导入目录 |

`--no-publish` 是兼容参数名，含义是“不导入本机目标目录”；此脚本不支持外部发布。

## 配乐识别

读 [identification.md](references/identification.md)，用 `identify_music.py` 比对自己的曲库。默认不扫描应用缓存、草稿或任意个人目录。只有使用者明确允许并提供具体目录时，才使用 `--cache-dir` 或 `--drafts-dir`。

相关性排名是候选证据，音量差是估计值。未经核对不声称准确识别；从缓存保存音频要确认匹配和使用权，并显式使用 `--save 曲名 --confirm-match`，不覆盖现有曲库文件。

## 文件与授权边界

- 默认不覆盖目标中已有同名文件，新版保留在本次独立输出目录。只有实际使用者明确要求替换才加 `--replace`；旧文件先备份到本次独立备份目录，记录真实备份路径。
- 不修改源视频、剪映草稿或缓存；不碰像素蛋糕应用内部目录和其他软件数据。目标目录由使用者指定，不能把作者的目录当成使用者的默认位置。
- 每条通过容器/时长与视频流一致性检查、响度/真峰值检查和全片解码后才可导入。指标通过不能证明人声主观清晰、音乐版权或内容身份；按实际听音和内容检查范围报告。
- 安装或更新本 skill 只处理 skill 文件，不自动处理视频、拷贝缓存、替换已有成片或发布。用户已经明确授权的常规制作步骤直接完成，不增加模板式重复确认。
