# 混音配方与选曲

## 配方

- 人声先对齐到 `-20 LUFS`，80 Hz 高通，2:1 轻压缩（阈值约 -15 dBFS）。
- BGM 从开头播放；1–4 kHz 区域衰减 3 dB，慢速增益推子将曲子的大起伏减半，范围约 -4 至 +3 dB。
- 开头淡入 1 秒，结尾淡出 2.5 秒；极短片的淡化窗口以实际长度为限。
- 音乐不够长时，截掉尾部渐弱和首尾静音，使用 3 秒交叉淡化循环；音乐主体不足以循环时报告具体失败，不换未经允许的素材。
- 默认人声高出 BGM `9 LU`，整体 `-16 LUFS`。限幅经 AAC 编码后检查真峰值 `≤ -1 dBTP`；整体响度允许与目标相差不超过 0.5 LU。
- 视频流直接复制；音频 AAC 192k、48 kHz 立体声。核对时长、视频包数量、视频流 SHA-256 和全片解码。每条另记录源文件 SHA-256 并确认制作后未变。

响度差、真峰值是测量目标，不能把它们当作已实际听过或一定清晰的保证。改曲目或调音量时仍执行同一核验。

## 选曲策略

下列都是策略别名，不是附带的音乐文件，也不是音频疗效声明。

| 别名 | 内容倾向 |
| --- | --- |
| 似水 | 默认舒缓底色；日常习惯、运动、实用提醒 |
| 舒缓 | 情感、心理、亲密关系、情绪主题 |
| 五音 | 传统养生及长期习惯主题，是否合适按内容判断 |
| 传说 | 故事、传统文化、误区与偏方辨析 |
| 轻快 | 节日或使用者明确要求的轻快主题 |

脚本按顺序匹配关键词；agent 还需看标题和话题的意思。可以在配置中把别名映射到自己的曲目，也可以在命令里对单条或区间指定曲目。其他音乐风格同样可由使用者显式指定，不需要保留作者的曲库习惯。
