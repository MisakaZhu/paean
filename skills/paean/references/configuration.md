# 本机配置

将 [config.example.json](../config.example.json) 复制到使用者工作目录，命名 `.paean-config.json`。两个脚本默认读取当前工作目录的这份文件，也可用 `--config /path/to/config.json` 指定。

**相对路径以配置文件所在目录为基准。** 没有配置文件时默认路径以当前工作目录为基准；CLI 明确给出的路径以当前工作目录为基准。运行时保存解析后的实际路径。

| 字段 | 默认 | 用途 |
| --- | --- | --- |
| `source_root` | `null` | 可选成片根目录；日期和 `latest` 写法需要该字段，完整文件夹/清单路径不需要 |
| `destination_dir` | `null` | 可选本机导入目录，例如用户自己的像素蛋糕导入文件夹；为空只保留工作区输出 |
| `work_dir` | `./paean-work` | 独立输出、临时数据、备份和本机记录 |
| `music_dir` | `./music` | 使用者自己的合法曲库，支持 m4a/mp3/aac/wav/flac/ogg |
| `ffmpeg` / `ffprobe` | 命令名 | 可指定已经安装的可执行文件完整路径，不附加命令参数 |
| `cache_dir` | `null` | 可选且须实际使用者允许读取的音乐缓存目录；默认不读应用缓存 |
| `drafts_dir` | `null` | 可选且须实际使用者允许读取的草稿目录；默认不读应用草稿 |
| `track_aliases` | 示例别名为空 | 将“似水/舒缓/五音/传说/轻快”等策略别名映射到自己的曲库文件名（不含扩展名），也支持能唯一匹配的名称片段 |

例如，曲库里有 `我的舒缓曲.wav`，可设置 `"舒缓": "我的舒缓曲"`。映射为空时按别名本身去曲库匹配；没有匹配项会报缺项，不能假设作者曲库已经安装。

成片清单支持：

```markdown
| 序号 | 标题 | 话题 | 成片 |
| ---: | --- | --- | --- |
| 1 | 日常习惯 | #日常 | [成片](<./videos/source video.mp4>) |
```

额外列可保留，标题以清单列为准。链接必须指向实际本机 MP4，网络 URL 不自动下载。标题中的文件名非法字符转为全角，空标题拒绝，Windows 保留名添加前缀。

工作区输出位于 `output/运行ID/序号/标题.mp4`，导入文件命名为 `标题.mp4`。同名导入目标默认保留；明确替换时备份在 `backup/时间-运行ID/序号/`。批量标题相同也不会互相覆盖预览文件。

安装条件：Python 3.10+、NumPy 1.26 或 2.x、FFmpeg/ffprobe。依赖声明在 [requirements.txt](../requirements.txt)；无自动安装代码。先检查现有环境，缺失时按当前使用者授权决定是否配置项目虚拟环境。FFmpeg 未包含 libsoxr 时自动采用内置重采样器。

私人配置、音乐、源视频、缓存、草稿和运行记录留在本机，不能上传到公开仓库；配置不应包含密码、访问令牌、签名 URL 或任何历史私人文案。
